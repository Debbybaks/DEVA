# Evidence and API contracts

Scientific envelopes contain experiment_id, scientific_sha256, timestamp and science. Canonical science is sorted-key compact finite JSON; SHA-256 excludes execution timestamp. Phase-1 schema 1.0 remains readable and unchanged. Evolution schema 2.0 adds full ancestry, split configurations, sensitivities, attacks and provenance. Capacity scientific model version remains 0.1; evolution orchestration version is 0.2.1.

`api.openapi.json` captures strict local request contracts. `apps/command/src/contracts.ts` validates response shape, earned verification levels, vector dimensions and matching scenario identities. `deva.view` is a read-only projection, not a second scientific engine. Graph traversal and visual scales are browser interaction logic; solver outputs and confidence calculations remain in Python.

Independent numerical audits reject forged flows, pass flags or demand vectors even when a reported residual is falsified. They do not certify LP optimality formally. Interactive Lab packages retain configuration, source losses, numerical results, audit, versions and canonical hash. Full original payloads remain available beyond projected views.


Schema 3.0 adds explicit unit-aware hydraulic configuration, source fingerprints, computed temporal states, operational isolation rounds, claim-ledger and proof objects. `hydraulicContracts.ts` rejects vector/identity mismatches and formal labels without UNSAT proof evidence. `hydraulic_view` converts SI to display units in Python. Old schemas and historical artifacts remain byte-identical.

# Initial test strategy
Use unittest with NumPy/SciPy. Unit tests validate schema, budget bounds, scenario arrays and Wilson edge cases. Numerical tests compare chain/parallel/disconnected networks to analytical service values; test monotonicity under added capacity and supply. Property-style seeded networks check conservation and bounds. Integration tests run synthesis, stress verification and full export. Regression tests freeze deterministic science output, not volatile timestamps. CLI tests invoke the public entrypoint and parse evidence. Infeasible optimisation and invalid numerical values must fail explicitly. Frontend interaction and browser end-to-end tests are required when the frontend exists; they are not claimed now. Run python -m unittest discover -s tests -v from repository root after installing the package.

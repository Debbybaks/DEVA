# DEVA command environment

Strict TypeScript/React local application consuming the Python API. `npm ci`, `npm run dev`; start the Python API on port 8000 first. Build: `npm run build`. Unit/interaction tests: `npm run test`. Real-browser tests: `npm run test:e2e` (Chromium path configurable with DEVA_CHROMIUM_PATH).

The network is the primary interface. GLSL motion represents relative volumetric flux, not velocity or travel time. Capacity width, failure rings, corridor grouping, conditional sampled risk and Wilson interval hatching are tied to supplied evidence. Pressure is untested here. Camera position, layer and scenario index are shared across paired designs. The 2D option preserves quantitative flows and component inspection; other layers are inspected through numerical evidence.

Evidence Mode exposes hashes, versions, streams, failed designs, raw failure/sensitivity records and provenance. All original 38/200 failures remain visible. No fake progress, generated simulation data, chatbot or AI avatar is used.

The scientific model is steady-state: there is no physical timeline, recovery or propagation animation. The scenario slider browses experiments. Animation controls affect visual flux only. Software renderer DPR is reduced; high frame cost while computing triggers a temporary 2D view, restored on completion. WebGPU and WASM are not introduced without evidence.

# Value of an observation

DEVA can rank a bounded candidate observation pool by noise-standardised hydraulic sensitivity. `sensor_placement.value_of_information` reports each sensor's log-determinant information score under fixed excitation; competing multi-sensor layouts expose complementarity and rank deficiency.

A large value means the local model predicts that measurement distinguishes declared uncertain parameter directions. It does not imply real-world economic benefit. Recommendations preserve the model point, uncertainty assumptions and observation coverage used to calculate them. No measurement is manufactured or silently inserted into calibration.

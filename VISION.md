# DEVA — Design, Engineering & Verification Autonomy
Named after Deborah. Design. Simulate. Break. Verify.

DEVA is a research engineering workbench that seeks evidence for competing designs, retains negative results, and exposes uncertainty. Its pipeline is UNDERSTAND → FORMALISE → GENERATE → MODEL → SIMULATE → ATTACK → OPTIMISE → VERIFY → EXPLAIN. Each stage has typed inputs, independent validation, and recorded outputs; no single prompt is a solver.

Version 1 designs a capacitated emergency water delivery network on a fixed directed topology. The initial scientific core is a local Python application, with a structured input interpreter rather than unvalidated natural-language inference. Its deliverable is a reproducible evidence package. A spatial command environment follows a working, tested model.

Non-goals: certified infrastructure design, universal engineering support, fabricated live computation, hydraulic or water-quality predictions, autonomous real-world control. Scientific depth precedes visual polish. A design may be rejected; no surviving candidate is a legitimate outcome.

## Phase-2 implementation status

Phase-2 now includes bounded design evolution, adversarial search, independently audited evidence, process orchestration and a TypeScript/WebGL command environment. Natural-language interpretation and real-world certification remain absent.

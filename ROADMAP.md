# Phased roadmap

0 — Research & architecture: these documents, repository and test protocol. Exit: explicit domain, claims, model and risks.
1 — Scientific core: validated structured input, max-min flow, nominal synthesis, reproducible experiment, residual checks, analytical tests. Exit: CLI produces honest evidence.
2 — Candidate generation & optimisation: nominal, uniform and robust LP alternatives; explicit parent relationships and costs. Initial finite alternatives included with Phase 1 integration; adaptive branching search remains future work.
3 — Failure Lab: declared pipe/corridor failures and seeded combined-event tests. Initial scenarios included; adaptive adversary, physical cascades and interactive observation remain future work.
4 — Verification: evidence hierarchy and numerical checks included; exact proof certificates remain unavailable.
5 — Visual command environment: implement the documented canvas on tested scientific results; progressive job events and accessibility tests.
6 — Intelligence: constrained natural-language interpretation with assumption review; bounded orchestration based on measurable improvement. No arbitrary code generation/execution.
7 — Evidence/reporting: initial full JSON packages; later professional report, artifact checksums and portable environment lock.
8 — Validation/polish: calibrated data, larger benchmarks, profile worker/UI, independent review, reproducibility across platforms.

Each phase must earn its claims. Initial scaffolding is not a completed research platform. No pressure, certification, live telemetry, 3D twin or temporal controls until justified and validated.

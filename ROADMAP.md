# DEVA roadmap — earned progress

| Stage | Implemented evidence | Remaining gate |
|---|---|---|
| Baseline | Original 16 tests; exact 200-trial scientific replay; unchanged artifact SHA | Cross-platform replay |
| Diagnosis | 38 failed cases with six controlled counterfactuals; topology checks; derived taxonomy | Calibrated event attribution and spatial demand patterns |
| Scientific expansion | Paired sensitivity, uncertainty intervals, factorial sweeps; analytical hydraulic solver tests | Hydraulic calibration, pressure-dependent demand and source constraints |
| Evolution | Full ancestry archive; two mutation operators; constrained training Pareto selection | Topology mutations, catalogue/MILP construction, broader benchmarks |
| Adversarial engineering | Bounded outage search, min-cut witnesses, demand thresholds; interactive source loss/degradation | Adaptive mixed continuous/discrete adversary; physical cascade/recovery |
| Verification | Independent numerical audits, hashes, scoped evidence labels and provenance | Exact certificates/model checking; mathematical/formal status unavailable |
| Runtime/performance | Two process workers, durable jobs/events, cached experiments, cancellation, SSE; measured throughput | Wall-time quotas, distributed queues, authenticated tenancy |
| Command environment | Scientific canvas/layers, paired design comparison, equations, ancestry, Pareto projection | More extensive accessibility/user studies and large-network LOD |
| GPU representation | Meaningful GLSL; software-renderer quality reduction and 2D fallback | Hardware GPU benchmarks; WebGPU only if justified |
| Evidence | Full JSON, Markdown report, provenance traversal, recorded Lab requests | Publication-grade PDF and independently reviewed models |
| Validation/polish | Numerical, generated-graph, integration, API, frontend and actual browser tests; reproducible experiments | Trusted EPANET/field benchmark, multi-seed research study |
| Intelligence | Deterministic autonomous stage orchestration and counterexample-informed mutation | Constrained natural-language formalisation; measured benefit from AI agents |

The current build is a substantial local research platform, not certified infrastructure software or a completed universal autonomous engineer. Future phases must continue to earn their claims. Temporal simulation, pressure in capacity designs, sensors, storage, contamination and physical recovery have prerequisites rather than decorative controls.
